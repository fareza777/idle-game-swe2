# DUSKSPIRE — Idle Realm

An original idle skilling RPG for Android (portrait). Inspired by the
philosophy of Realm Idle, Melvor Idle, CherryTree and IdleMMO — all code,
data, names and art are original.

**Core loop:** pick an activity → idle → gain XP / loot → level up →
craft & equip gear → fight stronger monsters → unlock new zones.

## Architecture — fully data-driven

Every monster, item, recipe, zone, quest and activity is a JSON record in
`web/data/` generated by `tools/generate_data.py`. Add a monster by adding
data — no engine changes needed.

```
web/            the game (vanilla JS, no build step)
  data/         generated JSON content
  js/           data.js engine.js ui.js audio.js main.js
  css/          portrait dark-fantasy theme
  assets/art/   70+ AI-generated art pieces (zones, bosses, classes, skills)
tools/
  generate_data.py   content generator (deterministic, seeded)
  generate_art.py    art pipeline (Replicate flux-schnell)
  smoke_test.js      headless engine test (node tools/smoke_test.js)
android/        Capacitor Android wrapper
apk/            prebuilt debug APK
```

## Play in a browser

```sh
npx serve web -l 8080        # then open http://localhost:8080
```

## Regenerate content

```sh
python3 tools/generate_data.py   # rewrites web/data/*.json
python3 tools/generate_art.py    # regenerates art (needs REPLICATE_API_TOKEN)
node tools/smoke_test.js         # engine sanity: gather→craft→fight→offline
```

## Build the Android APK

Requires Node 20+, JDK 17, Android SDK (platform 34 + build-tools).

```sh
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

For a release build, sign with your keystore and run `assembleRelease`.
